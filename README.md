# Matt Atkins Portfolio

[View the live portfolio](https://www.mattatkins.net)

Thanks for checking out my portfolio. I’m Matt Atkins, a product leader based in Philadelphia who enjoys building at the intersection of hardware and software.

My career started in data analysis and grew into launching connected-home, access-control, and resident-experience products at Comcast and SmartRent. Outside of work, I built the [Mercury extension for Raycast](https://www.raycast.com/atkinsmatt101/mercury) and started [Team Nate the Great](https://www.gonatego.com/) to support pediatric brain tumor research inspired by my son, Nate.

## About This Project

This portfolio tells my story as an interactive timeline instead of a traditional résumé. It brings professional milestones, personal chapters, photos, and the projects I care about into one place.

The experience includes a horizontal desktop timeline, a mobile-friendly vertical layout, light and dark themes, reduced-motion support, and live Philadelphia weather. It is built with Next.js, React, TypeScript, and Tailwind CSS.

## Development

Requires Node.js 22 through 24 and pnpm 10.

```bash
pnpm install
pnpm dev
```

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
