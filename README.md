# Matt Atkins Portfolio

A responsive professional and personal timeline built with Next.js 16, React 19, TypeScript, and Tailwind CSS 4.

The site includes a horizontal desktop timeline, a vertical mobile layout, light and dark themes, Vercel Analytics, and live Philadelphia weather from Open-Meteo.

## Getting Started

Requires Node.js 22 through 24 and pnpm 10.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The weather integration does not require environment variables.

## Development Commands

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

`pnpm audit` should return no known vulnerabilities before deployment.
